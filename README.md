# Python Automation Scripts

A collection of real-world automation tools built with Python.  
These scripts demonstrate practical automation skills used in file management, PDF processing, web scraping, and automated email workflows.

## 🚀 What I Do
I build clean, efficient, and customizable automation scripts using Python:

- File automation  
- Web scraping  
- PDF text extraction  
- Automated email sending  
- Custom Python tools for business workflows  

## 📂 Included Scripts

### 1. rename_files.py
Automatically renames files based on a pattern.  
Useful for large folders, bulk renaming, and organizing messy directories.

### 2. organize_files.py
Sorts files into folders based on file type.  
Creates categorized directories and moves files automatically.

### 3. extract_pdf_text.py
Extracts text from PDF files using PyPDF2.  
Ideal for processing documents, reports, and scanned forms.

### 4. web_scraper.py
A simple web scraper that fetches the title of a webpage.  
Useful for data collection, monitoring, and automation tasks.

### 5. auto_email.py
Sends automated emails using SMTP.  
Perfect for notifications, reports, and scheduled messages.

## 🛠 Technologies Used
- Python 3
